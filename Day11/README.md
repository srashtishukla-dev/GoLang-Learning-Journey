# Day 11 — Go Programming

## 📚 What I Learned

On Day 11 of my Go learning journey, I learned two important topics:

* **File Handling**
* **Packages**

## 📖 Topics Covered

### 1. File Handling

Learned the basics of working with files in Go and practiced reading and working with file-related operations.

Practice files include:

* `example.txt`
* `file1.go`

### 2. Packages

Learned how packages help organize Go code into separate, reusable components.

I practiced creating and using packages such as:

* `auth`
* `user`

I also worked with Go module files:

* `go.mod`
* `go.sum`

and used `main.go` to work with the packages.
